## Fresh machine setup (reproducing this environment)

### 1. Prerequisites

- Install uv: https://docs.astral.sh/uv/getting-started/installation/
- Install CUDA toolkit 12.8 (or compatible): https://developer.nvidia.com/cuda-toolkit-archive
- Ensure `nvcc` is on PATH and `CUDA_HOME` points to the toolkit:

```bash
export CUDA_HOME=/usr/local/cuda-12.8
```

### 2. Create the venv and install PyTorch

`torch` is intentionally absent from `pyproject.toml` because the correct wheel
depends on the host's CUDA version. The venv must exist before torch can be
installed into it, so create it first:

```bash
uv python pin 3.12
uv venv                  # creates .venv with Python 3.12, nothing else installed yet

# install torch into the fresh venv
.venv/bin/pip install torch torchvision torchaudio \
    --index-url https://download.pytorch.org/whl/cu128
```

### 3. Sync the remaining deps

```bash
uv sync --no-build-isolation --inexact
```

`--inexact` keeps torch/torchvision in place (they're not in the lockfile).
`--no-build-isolation` is required because some packages (iopath) need torch
available at build time.

### 4. Install SAM-2 (editable, with CUDA extension)

```bash
uv pip install --no-build-isolation -e .
# verify
uv run python -c "import torch; import sam2._C; print('sam2 CUDA ext OK')"
```

To skip the CUDA extension (e.g. no nvcc available):

```bash
SAM2_BUILD_CUDA=0 uv pip install --no-build-isolation -e .
```

The CUDA extension enables mask hole-filling post-processing. Omitting it is safe —
inference still works correctly in most cases.

### 5. Install GroundingDINO (editable, requires nvcc)

```bash
uv pip install --no-build-isolation -e grounding_dino
# verify
uv run python -c "import groundingdino.util.inference; print('groundingdino OK')"
```

### 6. Full verification

```bash
uv run python -c "
import torch, torchvision, sam2, sam2._C, groundingdino, supervision, transformers, timm
print('torch:', torch.__version__)
print('cuda:', torch.cuda.is_available(), torch.cuda.get_device_name(0))
print('sam2._C: OK')
print('supervision:', supervision.__version__)
"
```

## Known quirks

**`sam2._C` import order** — `sam2._C` must be imported after `torch` (so
`libc10.so` is already loaded). All demo scripts import torch first, so this
is not an issue in practice. Importing `sam2._C` in isolation raises
`ImportError: libc10.so: cannot open shared object file`.

**`dds-cloudapi-sdk` not in uv deps** — v0.5.3 has a broken `build-system.requires`
(missing `setuptools`), which causes `uv sync` to fail at the lock step for all
users, even those who never use the GD 1.5 / DINO-X API. Install it manually
only when needed: `pip install dds-cloudapi-sdk --upgrade`.

**`timm` deprecation warning** — `FutureWarning: Importing from timm.models.layers
is deprecated` appears when loading groundingdino. This is a groundingdino
upstream issue; it does not affect functionality.
